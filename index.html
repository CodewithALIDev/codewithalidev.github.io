PDC WITH SRN TRANSACTION

Post Dated Cheque • Supplier Payment • Financial Automation

Developed a comprehensive Post Dated Cheque (PDC) with SRN Transaction module within the Accounts & Financial Management System. The solution enables finance teams to generate supplier payments directly against pending Store Receiving Notes (SRNs),Purchase Orders (PO's),Service Purchase Orders (SPO's) while automatically managing cheque details, voucher entries, payment allocation, outstanding balances, and General Ledger integration. The module streamlines supplier settlement with complete financial traceability and enterprise-grade approval controls.

Enterprise Features & Business Workflow

  • Smart Payment Reference Popup A dedicated popup window opens from the Payment Reference button, providing an intelligent interface for selecting supplier transactions before voucher generation.
  • Advanced Search & Filtering Users can filter transactions using From Date, To Date, SRN Number, Purchase Order (PO), Service Purchase Order (SPO), Supplier, and GL Code to quickly locate pending payments.
  • GL Code Driven Data Retrieval The system automatically displays only the outstanding supplier transactions linked to the selected General Ledger account, ensuring accurate financial processing.
  • Dynamic Payment Type Selection Supports multiple payment modes including:
    • Bill Payment (SRN)
    • Advance Payment (Purchase Order)
    • Service Payment (Service Purchase Order)
    The displayed records change dynamically based on the selected transaction type.
  • Bulk Multi-Selection Processing Users can select any combination of pending SRNs, Purchase Orders, or Service Purchase Orders using checkboxes, allowing multiple supplier invoices to be settled through a single cheque transaction.
  • Toggle Select / Deselect All One-click Toggle functionality instantly selects or deselects every displayed transaction, significantly reducing processing time for bulk supplier payments.
  • Real-Time Financial Calculations The popup continuously calculates SRN Amount, Paid Amount, Current Amount, Remaining Balance, and automatically updates the voucher Grand Total as records are selected or modified.
  • Partial Payment Facility Finance users can enter a custom payment amount in the Current Amount field, enabling partial settlements while automatically carrying forward the remaining balance for future payments.
  • Automatic Outstanding Balance Validation Fully paid transactions are automatically excluded, while only outstanding balances remain available for payment, preventing duplicate settlements.
  • Integrated Voucher Generation After confirmation, the selected transactions are automatically transferred into the Post Dated Cheque voucher, generating the corresponding accounting entries and supplier ledger postings.
  • Supplier Ledger & GL Integration Every payment updates the supplier ledger, General Ledger accounts, cheque information, and financial balances in real time, maintaining complete accounting integrity.
  • Enterprise Oracle Forms Architecture Developed using Oracle Forms 11g, PL/SQL Procedures, Packages, Database Triggers, and Oracle Database with optimized SQL for high-volume enterprise financial transactions.
